# Reporting security issues / 安全问题报告

Please do not open a public issue for a security problem in Caret, and please keep the details private until it is fixed.

- Email <support@tenonai.cn> with "Caret security" in the subject. We reply within one business day.
- Or use this repository's private "Report a vulnerability" on GitHub.
- Tenon AI's [security policy](https://tenonai.cn/security/#report) describes how reports are handled.

Include the affected version or commit, steps to reproduce and the impact you expect. Never include real passwords, keys, tokens or personal data, such as the API key for your model service, or code you cannot share.

Fixes go into the latest release.

Scope: the code in this repository, and caret.tenonai.cn run by Tenon AI.

---

发现 Caret 的安全问题，请不要开公开的 issue，也请在修好之前不要公开细节。

- 邮件：<support@tenonai.cn>，标题注明「Caret 安全」，我们会在 1 个工作日内回复。
- 或者用本仓库 GitHub 的「Report a vulnerability」（私下报告）。
- 报告和答复的做法见榫卯 Tenon AI 的[安全政策](https://tenonai.cn/zh/security/#report)。

请写明：受影响的版本或提交、复现步骤、你认为的影响。请不要在报告里放真实的密码、密钥、令牌或个人数据，以及模型服务的 API Key 和你不能公开的代码。

修复只进最新发布的版本。

范围：这个仓库里的代码，以及榫卯 Tenon AI 运行的 caret.tenonai.cn。
