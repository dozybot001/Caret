# 安全问题报告 / Reporting security issues

发现 Caret 的安全问题，请不要开公开的 issue。

- 邮件：<support@tenonai.cn>，标题注明「Caret 安全」。
- 或者用 GitHub 的「Report a vulnerability」（私下报告）。
- 报告和答复的做法见榫卯 Tenon AI 的[安全政策](https://tenonai.cn/security/#report)。

请写明：受影响的版本或提交、复现步骤、你认为的影响。请不要在报告里放真实的 API Key 或你不能公开的代码。

范围：这个仓库里的代码和 caret.tenonai.cn 上的页面。模型服务商的接口不在范围内，请直接报告给服务商。

Please do not open a public issue for a security problem in Caret. Email <support@tenonai.cn> with "Caret security" in the subject, or use GitHub's private "Report a vulnerability". Tenon AI's [security policy](https://tenonai.cn/security/#report) describes how reports are handled. Include the affected version or commit, steps to reproduce and the impact you expect. Never include real API keys or code you cannot share. The scope is the code in this repository and the pages on caret.tenonai.cn; report problems in a model provider's API to that provider.
