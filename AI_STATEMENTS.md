# AI Statements (Tags)

Use **one tag** per repo. Keep tags consistent across all your projects.

## Tags

- **`ai-build`**: Highest involvement — AI built most of the project. Human reviewed/approved.
- **`ai-assisted`**: AI helped during development. Human reviewed/approved.
- **`ai-refactor`**: AI mainly reorganized/refactored existing work. Human reviewed/approved.
- **`ai-doc-only`**: Lowest involvement — AI only contributed to documentation (e.g., README). Human reviewed/approved.

## README format (recommended)

```md
## AI Statement

Tag: `ai-build`
Reference: `AI_STATEMENTS.md`
```
